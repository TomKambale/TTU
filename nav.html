Dropdown Navigation Menu for TTU University

This is a fully responsive dropdown navigation menu with the following features:

Features:

  • Responsive Design: Works on desktop, tablet, and mobile devices
  • Multi-level Dropdowns: Regular dropdowns with nested links
  • Mega Menu: For the Academics section with multiple columns
  • Mobile-Friendly: Hamburger menu for mobile with click-to-expand dropdowns
  • TTU Branding: Uses your university's green color scheme
  • Smooth Animations: CSS transitions for dropdown appearance
  • Accessibility: Proper ARIA attributes and keyboard navigation support

How to Integrate with Your Existing Site:

To add this dropdown navigation to your existing TTU website, follow these steps:

// 1. Copy the HTML structure from the <nav class="navbar"> section
// 2. Copy the CSS from the <style> tag (navbar-related styles only)
// 3. Copy the JavaScript from the <script> tag at the bottom
// 4. Update the links to match your actual page URLs
// 5. Customize the dropdown items based on your site structure

Desktop Behavior:

On desktop screens (width > 1024px), dropdowns appear on hover. The mega dropdown for Academics shows a multi-column layout with categorized links.

Mobile Behavior:

On mobile screens (width ≤ 1024px), the menu collapses into a hamburger icon. Dropdowns expand on click with smooth animations.

Customization Tips:

  • Change colors by modifying the CSS variables at the top of the <style> tag
  • Add/remove menu items by editing the HTML structure
  • Adjust breakpoints in the media query for different screen sizes
  • Replace Font Awesome icons with your own images or different icon sets

Test the Navigation:

Resize your browser window to see the responsive behavior. On mobile size, click the hamburger icon to open the menu, then click on "Academics" or other dropdown items to expand them.
